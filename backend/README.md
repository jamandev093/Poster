# Poster Backend

Authoritative TypeScript API for Poster.

## Responsibilities

- Client authentication and organization access
- Admin authentication and authorization
- Advertising requests and campaigns
- Wallet balances and campaign allowances
- Razorpay funding orders and signed webhooks
- Invoices, refunds, settlements, and immutable ledger entries
- Validated analytics and traffic-quality records
- Publisher and content-ingestion APIs
- Audit history and operational security

## Commands

npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npm start
